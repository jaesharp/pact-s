# PACT System Images

This directory contains images used throughout the PACT System documentation.

## Directory Structure

Images should be organized in subdirectories based on their primary area of use:

- `architecture/` - System architecture diagrams
- `concepts/` - Conceptual illustrations
- `protocols/` - Protocol flow illustrations
- `screenshots/` - Application screenshots
- `tutorials/` - Images for tutorials and guides

## Image Naming Convention

Please follow these naming conventions for images:

- Use lowercase
- Use hyphens instead of spaces
- Include a descriptive name
- Include the date (YYYYMMDD) for versioned images

Example: `knowledge-graph-structure-20250515.png`

## Image Formats

- Use SVG for diagrams and illustrations when possible
- Use PNG for screenshots and other raster images
- Use JPEG only for photographs

## Usage Guidelines

When referencing images in markdown files:

```markdown
![Alt text describing the image](../images/category/image-name.png)
```

Include meaningful alt text for accessibility.
