# PACT-System Project Plans

This directory contains strategic planning documents, historical records of major operations (like project merges), and ongoing plans for the development and evolution of the PACT-System framework.

## Index of Planning Documents

*   **`CHANGELOG.md` (in project root)**: While not in this directory, the main [../../CHANGELOG.md](../../CHANGELOG.md) tracks overall project changes.

*   **[`development_roadmap_and_tasks.md`](./development_roadmap_and_tasks.md)**:
    *   A high-level overview of key development areas, ongoing tasks, and future considerations for the PACT-System, serving as a conceptual issue tracker.

*   **[`directory_structure_plan.md`](./directory_structure_plan.md)**: 
    *   Outlines the target directory structure for the PACT-System project and strategies for its ongoing maintenance and evolution.

*   **[`documentation/README.md`](./documentation/README.md)** (Main Documentation Strategy & Index):
    *   A comprehensive strategy for creating user documentation for the PACT-System framework, covering goals, personas, content types, BDD integration, development processes, and delivery. Links to detailed sub-plans.

*   **[`language_configuration_strategy.md`](./language_configuration_strategy.md)**: 
    *   Analyzes the use of Dhall for configuration and potentially source code, recommending a hybrid approach with TypeScript for the PACT-System.

*   **[`master_project_plan.md`](./master_project_plan.md)**:
    *   The central, evolving plan and checklist for the PACT-System project, consolidating progress, ongoing tasks, and future work derived from collaborative sessions.

*   **[`multi_repo_architecture_docs_plan.md`](./multi_repo_architecture_docs_plan.md)**:
    *   Outlines the plan to create and develop detailed documentation for the PACT-System multi-repository architecture (based on the "Five Ws" concept), primarily linking to documents within [./future-research/](./future-research/).

*   **[`ontology_and_formalism/README.md`](./ontology_and_formalism/README.md)** (Ontology & Formalism Overview & Index):
    *   Outlines the plan to define a formal OWL2 ontology for the PACT-System and establish an XML/XSD-based workflow, potentially with Haskell/Dhall integration. Links to detailed sub-plans.

*   **[`testing_and_verification/README.md`](./testing_and_verification/README.md)** (Testing Strategy Overview & Index):
    *   A comprehensive testing strategy for the PACT-System framework, covering unit, integration, system, and compliance testing, as well as tools and CI/CD integration. Links to detailed sub-plans.

*   **[`vcs_strategy.md`](./vcs_strategy.md)**: 
    *   Outlines the version control system (Git) strategy, including branching models, commit conventions, PR processes, and version management for the PACT-System project.

### Archived or Reference Materials

*   **[`merger.md`](./merger.md)**:

*   **[`merge_questions.md`](./merge_questions.md)**: 
    *   A historical log of questions and answers that arose during the initial project merge process. Primarily for reference.

*   **[`symbolic_tools_update_plan.md`](./symbolic_tools_update_plan.md)**:
