# PACT-System-Core Repository (The "What")

Content to be developed as per the PACT-System multi-repository architecture plan (`../architecture-overview.md`).

This repository is envisioned to contain the PACT-System governance rules themselves, across different temporal versions (t0, t1, t2), including compiled versions, generated governance artifacts, release snapshots, and version metadata with signatures.
 
Its primary responsibilities include:
- Maintaining the source of truth for governance rules.
- Providing access to different temporal PACT-S Versions.
- Managing version transitions.
- Ensuring cryptographic verification of rule integrity.
